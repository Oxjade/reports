# Cronos: Ethermint Audit (third-party reference material)

**Source:** `report_ethermint_1.2_final_public.pdf` (39 pp), present twice in this tree
(identical files in `repo/cronos/docs/audit/` and `repo/v179/docs/audit/`)

## Note on provenance

**This is not my assessment.** It is the public Ethermint v1.2 audit report, included in
the Cronos source tree and retained here as third-party reference material consulted
during the Cronos engagement. The duplicate copies in the two checked-out repo versions
are byte-identical.

## Relevance

Held as a baseline for comparing inherited consensus-layer code against the audit
history already published upstream. Any observed issue in Ethermint-derived code should be
checked against this report first to determine whether it is a known, already-tracked
class of defect.

Consult it as reference only; findings and credit belong to the original auditors.
